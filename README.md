# Ganesh Shingade — Cyber-Vedic 3D Data Portfolio

An interactive, high-performance 3D portfolio powered by Three.js WebGL and inspired by Vedic mythology, customized for **Ganesh Shingade** (Data Analyst & Data Scientist).

## 🚀 Features

- **3D Sudarshan Chakra (सुदर्शन चक्र)**: Rotating 108-tooth golden chakra with glowing turquoise core, interactive network graph, and floating data tags (`Power BI`, `SQL`, `Pandas`, `NumPy`, `EDA`, `LLMs`).
- **Samudra Manthan (समुद्र मंथन)**: Churning ocean wave vertex shader, Mount Mandara, the serpent Vasuki with floating data packets, and the glowing Amrit Kalasha.
- **Padma (पद्म - The Lotus)**: Blooming 32-petal sacred lotus carrying 8 orbiting core analytical tools (`Python`, `SQL`, `Power BI`, `Pandas`, `NumPy`, `Seaborn`, `Excel`, `LLMs`).
- **Chakravyuha (चक्रव्यूह)**: Concentric rotating defense formation representing the analytical pipeline stages (`cleanse`, `explore`, `model`, `visualize`, `deliver`) featuring Ganesh's major projects:
  - **Human Visual Attention Intelligence System** (Streamlit, MediaPipe, DeepFace, Computer Vision, Cognitive AI)
  - **Diwali Sales Analysis** (Python, Pandas, NumPy, Seaborn, Matplotlib)
  - **Food Order History Analysis** (EDA, customer retention, logistics optimization)
  - **Car Dekho Valuation Analysis** (SQL relational queries, depreciation modeling)
- **Dharma Path (धर्म पथ)**: Ascending spiral pathway with glowing milestone markers for Ganesh's education (M.Tech at GCOEC, B.Tech at MIT Aurangabad/DBATU) and certifications (Oracle Cloud Data Science, Google Cloud GenAI, etc.).
- **Deepa (दीप - The Sacred Lamp)**: Flickering golden Akhand Diya, rising glowing embers, rotating yantra mandala with 108 beads, and a radiant ॐ glyph.
- **Responsive & Modern HUD**: Live progress bar, glassmorphism panels, mobile horizontal touch swipe for cards/timeline, and one-click copy email button.

## 🛠️ How to View Locally

Simply double-click [`index.html`](index.html) in your browser (Google Chrome, Microsoft Edge, Brave, Firefox, Safari).

Or serve it with any local HTTP server:
```bash
# Python 3
python -m http.server 8000

# or Node.js npx
npx serve
```
Then visit `http://localhost:8000`.

## 🌐 Deploy to GitHub Pages

1. Create a new GitHub repository named `mytho-portfolio` or `<your-username>.github.io`.
2. Push `index.html` to the repository:
   ```bash
   git init
   git add index.html README.md
   git commit -m "Initial commit of 3D Mytho Portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. In GitHub, go to **Settings** > **Pages** > select **Deploy from a branch** > branch **main** / **root** > Save.
4. Your website will be live in a few minutes at `https://<your-username>.github.io/<repo-name>/`.
